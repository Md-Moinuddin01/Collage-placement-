A modern and responsive **College Placement Preparation Platform** built to help students prepare for campus placements with aptitude practice, coding resources, interview preparation, company-wise questions, resume building, and progress tracking.

> Empowering students to crack their dream placements with structured learning.

---

## 🚀 Features

- 📚 Aptitude Preparation
  - Quantitative Aptitude
  - Logical Reasoning
  - Verbal Ability
  - Data Interpretation

- 💻 Coding Practice
  - DSA Questions
  - Programming Challenges
  - Company-wise Coding Problems
  - Online Judge Links

- 🎤 Interview Preparation
  - HR Interview Questions
  - Technical Interview Questions
  - Behavioral Questions
  - Mock Interview Resources

- 📄 Resume Builder
  - Resume Templates
  - Resume Tips
  - ATS Friendly Resume Guide

- 🏢 Company Preparation
  - Company-wise Interview Experience
  - Placement Papers
  - Frequently Asked Questions

- 📈 Student Dashboard
  - Progress Tracking
  - Daily Goals
  - Completed Topics
  - Performance Analytics

- 🌙 Responsive UI
  - Mobile Friendly
  - Dark Mode Support
  - Clean and Modern Design
